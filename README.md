# Испорченный интерфейс

Автономная браузерная мини-игра о финансовой и цифровой безопасности. Игрок работает с интерфейсом вымышленного мобильного банка, замечает признаки мошенничества и выбирает безопасные действия.

## Запуск

Сборка и внешние зависимости не требуются. Откройте `index.html` в современном браузере либо запустите из папки проекта любой статический HTTP-сервер, например:

```powershell
python -m http.server 4173
```

После этого откройте `http://localhost:4173`.

## Структура

- `index.html` — вся игра: разметка, стили, сценарий и игровая логика;
- `Испорченный-интерфейс-ТЗ.md` — техническое задание и описание механик.

Игра работает локально и не требует backend, авторизации или передачи персональных данных.
